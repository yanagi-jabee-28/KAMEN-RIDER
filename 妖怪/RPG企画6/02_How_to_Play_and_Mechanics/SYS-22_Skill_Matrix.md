# [SYS-22] Skill Matrix (Player Facing)

このファイルは「プレイヤー向け術式索引の視点」から書かれています。全技を覚えるためではなく、役割選択の迷いを減らすための一覧です。

## 最初に読む3行

- まず「役割別の優先技」で、自分の編成に足りない役割を確認する。
- 次に「キャラ別優先10技」で、1キャラにつき2-3技だけ先に覚える。
- 行き詰まったら「詰まり方ごとの再編テンプレ」で編成を入れ替える。

## 用語の最短辞典

- ヘイト集約: 敵の狙いを前衛へ集め、後衛被弾を減らすこと。
- 剥離: 防御・強化をはがして、次の攻撃を通しやすくすること。
- 攪乱: 行動順や命中を崩して、敵の予定を外すこと。
- 収束: 崩した後に火力を集中させて短く勝ち切ること。

## 役割別の優先技

| 役割 | 主担当 | 優先効果 |
|---|---|---|
| 壁役（斥候） | うかみ（斥候） | ヘイト集約、被弾受け、行動維持 |
| 壁役（重壁） | マヒト | 正面受け、全体軽減、耐久制御 |
| 壁役（行者） | 行者うかみ | 自律介入、呪い対処、帰還導線の維持 |
| 攪乱 | ウズ | 行動順乱し、命中妨害、予測崩し |
| 剥離 | スクナ/タチバナ | 防御低下、状態異常、相殺補助 |
| 再起動 | マヒト | 鍛造段階解禁、修復補助、破砕再始動 |
| 停止 | ワカヒコ | 危険行動停止、高精度制圧 |
| 可変 | ミコト | 神写しで不足ロール補完 |

## 運用のコツ

- 同じ技を連打せず、役割を往復する
- 苦境時の使用は神写し理解度の伸びが大きい
- 付喪神化は強いが、耐久消耗が重い

## 3. パーティ雛形（初心者向け）

### 安定型

- うかみ / ミコト / スクナ / マヒト
- 特徴: 受け・修復・剥離のバランスが良い。

### 攪乱型

- ミコト / ウズ / タチバナ / ワカヒコ
- 特徴: 予測線崩しと行動停止で短期決着を狙う。

### 終盤対応型

- ミコト / マヒト / タチバナ / ワカヒコ
- 特徴: 破壊・分散・停止で高難度の事故を減らす。

## 4. よくある詰まりと対処

| 詰まり方 | 原因 | 対処 |
|---|---|---|
| 耐久だけ先に尽きる | 剥離前に火力連打している | スクナ/マヒトで先に防御を剥がす |
| 空殻が連鎖する | 情念回復行動を省略している | 息を整える、連撃熱伝導を使う |
| 予測線通りに壊滅する | 停止/攪乱が不足 | ウズの遅延、ワカヒコの停止を先に打つ |
| 立て直せない | 役割重複で穴がある | ミコトの神写しで欠けた役割を補完 |

## 5. プレイヤー向け注意

- 強い技を連打するより、役割の切り替えが勝率を上げる。
- 代償付き技は「押し切る場面」で使うと価値が高い。
- うかみ離脱区間は難しくて正常。設計意図として受け止める。
- うかみ離脱後は、マヒトの重壁運用（鉄の城壁/鞴の大風）を軸に再編すると崩れにくい。
- 第4幕以降は「斥候うかみ」と「行者うかみ」を別枠として判断すると編成の迷いが減る。

## 6. 幕遷移ごとの推奨編成ガイド

| フェーズ | 推奨編成 | 狙い | 切替トリガー |
|---|---|---|---|
| 第1幕（導入） | うかみ / ミコト / スクナ / 任意 | 生存基盤を安定化 | 空殻が2回以上連続したら回復比率を上げる |
| 第2幕前半（敗北学習） | うかみ / ミコト / スクナ / ウズ | 耐久消耗を抑えながら情報収集 | 白堊の回廊で耐久先枯れが発生した時 |
| 第2幕後半（鍛造転換） | ミコト / タチバナ / マヒト / スクナ | 剥離と修復を回しつつ、重壁運用を先に習熟 | 鍛造段階が上がったタイミング |
| 第3幕（停止重視） | ミコト / ワカヒコ / タチバナ / マヒト | 危険ターン停止と局所制圧 | 危険予測線が2本以上重なる時 |
| 第4幕（位相対応） | ミコト / マヒト / ワカヒコ / ウズ | 領域混在への再計画力を確保 | 無菌と泥沼が交互発生した時 |
| 終幕 | ミコト / ワカヒコ / マヒト / タチバナ | 神託破壊と押し切りを両立 | 予測線破壊条件が未達の時 |

## 7. 危険ターン優先度（簡易ルール）

1. 停止: ワカヒコ、うかみの中断技で危険行動を止める。
2. 攪乱: ウズで予測線を乱し、確定行動を崩す。
3. 剥離: スクナ/マヒト/タチバナで防御とバフを剥がす。
4. 収束: ミコトで不足ロールを補って火力を通す。

## 8. 詰まり方ごとの再編テンプレ

| 症状 | まず外すもの | まず入れるもの |
|---|---|---|
| 武器破損が早すぎる | 高連打アタッカー1枠 | マヒト優先（次点スクナ） |
| 行動前に壊滅する | 純火力枠1つ | ワカヒコ or ウズ |
| 立て直しが遅い | 過剰なデバフ枠 | ミコト補助技 + 回復導線 |
| 予測線を読んでも負ける | 同系統技の連投 | 停止→剥離→収束の順番運用 |
