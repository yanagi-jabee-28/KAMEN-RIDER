# [SYS-22] Skill Matrix (Player Facing)

このファイルは「プレイヤー向け術式索引の視点」から書かれています。全技を覚えるためではなく、役割選択の迷いを減らすための一覧です。

## 役割別の優先技

| 役割 | 主担当 | 優先効果 |
|---|---|---|
| 壁役 | うかみ | ヘイト集約、被弾受け、行動維持 |
| 攪乱 | ウズ | 行動順乱し、命中妨害、予測崩し |
| 剥離 | スクナ/タチバナ | 防御低下、状態異常、相殺補助 |
| 再起動 | マヒト | 鍛造段階解禁、修復補助、耐久制御 |
| 停止 | ワカヒコ | 危険行動停止、高精度制圧 |
| 可変 | ミコト | 神写しで不足ロール補完 |

## 運用のコツ

- 同じ技を連打せず、役割を往復する
- 苦境時の使用は神写し理解度の伸びが大きい
- 付喪神化は強いが、耐久消耗が重い

## 1. キャラ別「まず覚える技」

### ミコト（可変ハブ）

- 言継ぎ: 仲間技との共鳴を進める基幹。
- 命の還流: 空殻からの復帰手段。
- 代受の誓い: 崩れた前線を再接続する。

### うかみ（壁・受け）

- 獣の咆哮: 危険ターンを中断する。
- 鉄の城壁系: ヘイト集中で後衛を守る。
- 法螺の轟き（継承後はミコトも使用）: 情念循環を加速。

### スクナ（剥離・制御）

- 強酸の霧散: 防御が高い敵への基本解。
- 冷却の服用: 過熱対策と回復を同時実行。
- 忘却の霧: 厄介な特殊行動を止める。

### ウズ（攪乱）

- 乱調の裏拍: 行動順を崩す入口。
- 幻惑の舞: 命中事故を減らす。
- 狂騒の引力: 味方側の情念再循環を補助。

### タチバナ（自傷デバフ）

- 悲哀の波紋: 全体弱体の基本。
- 自傷・土偶: 高圧局面の突破口。
- 執着の血潮: ダメージ分散で壊滅を防ぐ。

### マヒト（鍛造・粉砕）

- 武具叩き折り: 敵の武器優位を崩す。
- 槌の轟き: 強化済み敵への回答。
- 命の金継ぎ: 自身代償で味方復帰を支える。

### ワカヒコ（停止・狙撃）

- 影縫いの刃: 危険行動を止める。
- 先駆けの矢: 先手で起点を潰す。
- 返し矢の呪い: 反動込みで火力を押し上げる。

## 2. 幕ごとの運用変化

| 幕 | 戦術キー |
|---|---|
| 第1幕 | 受けて繋ぐ |
| 第2幕 | 敗北学習から鍛造転換へ |
| 第3幕 | 停止と再構成 |
| 第4幕 | 位相対応 |
| 終幕 | 神託破壊 |

詳細な幕背景とイベント意図は [../01_Story_and_Characters/NAR-11_Act_Detail_Guide.md](../01_Story_and_Characters/NAR-11_Act_Detail_Guide.md) を参照。

## 3. パーティ雛形（初心者向け）

### 安定型

- うかみ / ミコト / スクナ / マヒト
- 特徴: 受け・修復・剥離のバランスが良い。

### 攪乱型

- ミコト / ウズ / タチバナ / ワカヒコ
- 特徴: 予測線崩しと行動停止で短期決着を狙う。

### 終盤対応型

- ミコト / マヒト / タチバナ / ワカヒコ
- 特徴: 破壊・分散・停止で高難度の事故を減らす。

## 4. よくある詰まりと対処

| 詰まり方 | 原因 | 対処 |
|---|---|---|
| 耐久だけ先に尽きる | 剥離前に火力連打している | スクナ/マヒトで先に防御を剥がす |
| 空殻が連鎖する | 情念回復行動を省略している | 息を整える、連撃熱伝導を使う |
| 予測線通りに壊滅する | 停止/攪乱が不足 | ウズの遅延、ワカヒコの停止を先に打つ |
| 立て直せない | 役割重複で穴がある | ミコトの神写しで欠けた役割を補完 |

## 5. プレイヤー向け注意

- 強い技を連打するより、役割の切り替えが勝率を上げる。
- 代償付き技は「押し切る場面」で使うと価値が高い。
- うかみ離脱区間は難しくて正常。設計意図として受け止める。

## 6. 幕遷移ごとの推奨編成ガイド

| フェーズ | 推奨編成 | 狙い | 切替トリガー |
|---|---|---|---|
| 第1幕（導入） | うかみ / ミコト / スクナ / 任意 | 生存基盤を安定化 | 空殻が2回以上連続したら回復比率を上げる |
| 第2幕前半（敗北学習） | うかみ / ミコト / スクナ / ウズ | 耐久消耗を抑えながら情報収集 | 白堊の回廊で耐久先枯れが発生した時 |
| 第2幕後半（鍛造転換） | ミコト / タチバナ / マヒト / スクナ | 剥離と修復の同時運用 | 鍛造段階が上がったタイミング |
| 第3幕（停止重視） | ミコト / ワカヒコ / タチバナ / マヒト | 危険ターン停止と局所制圧 | 危険予測線が2本以上重なる時 |
| 第4幕（位相対応） | ミコト / マヒト / ワカヒコ / ウズ | 領域混在への再計画力を確保 | 無菌と泥沼が交互発生した時 |
| 終幕 | ミコト / ワカヒコ / マヒト / タチバナ | 神託破壊と押し切りを両立 | 予測線破壊条件が未達の時 |

## 7. 危険ターン優先度（簡易ルール）

1. 停止: ワカヒコ、うかみの中断技で危険行動を止める。
2. 攪乱: ウズで予測線を乱し、確定行動を崩す。
3. 剥離: スクナ/マヒト/タチバナで防御とバフを剥がす。
4. 収束: ミコトで不足ロールを補って火力を通す。

## 8. 詰まり方ごとの再編テンプレ

| 症状 | まず外すもの | まず入れるもの |
|---|---|---|
| 武器破損が早すぎる | 高連打アタッカー1枠 | マヒト or スクナ |
| 行動前に壊滅する | 純火力枠1つ | ワカヒコ or ウズ |
| 立て直しが遅い | 過剰なデバフ枠 | ミコト補助技 + 回復導線 |
| 予測線を読んでも負ける | 同系統技の連投 | 停止→剥離→収束の順番運用 |
