# アシブネノミコト 〜天降る御子と、星屑の大地〜

# [WRD-01] Core Vision and Theme

本作の世界観・遊び方・物語の入口となる案内文書です。

## 最初に押さえる3つのキーワード

1. **停滞の琥珀（イザナギの理）**
	喪失を恐れるあまり、世界を不変のまま凍らせようとする神々の意志。
2. **還流と金継ぎ（人の営み）**
	傷を受け入れ、壊れたものを修復しながら命をつないでいく地上の作法。
3. **要石（ミコトの宿命）**
	感情を持たない器として設計され、世界を静止させるために造られた役割。

## 読み分けポータル（三層）

情報を削らずに読み解くため、次の3層で潜る深さを選びます。

1. 概念と情景（Vision and Narrative）
2. 体験の力学（Experience and Mechanics）
3. 論理と数理（Data and Logic）

共通語彙の基準は、[WRD-02_Protected_Vocabulary.md](WRD-02_Protected_Vocabulary.md) を参照してください。

## 1. プロジェクト基本情報 (基礎情報)

> **注記:** 第1幕「胎／白の輪郭」は「停滞の可視化」をテーマとし、チュートリアル段階で大宜都比売と探女を配置することが提案されている。教育的コストはかかるが、世界観の理解深化という点で極めて高い波及効果が見込まれる。
- **プロジェクトコード:** RPG企画6
- **タイトル:** アシブネノミコト 〜天降る御子と、星屑の大地〜
- **ジャンル:** 和風神話ダークファンタジーRPG
- **遊びのコア:** 「泥臭い修復と継承」を体感する、痛みを伴う旅。

## 2. コア・テーマと基盤哲学 (前提知識)

**「悲哀による永遠の結晶化（停滞）」と「傷を抱えた命の還流（変転）」の衝突。**

この世界には二つの「慈悲」がある。
天の神々（イザナギの理）は喪失の再発を拒み、世界を「不変の結晶（琥珀）」として停止させようとする。
地上の者は死と別れを受け入れ、壊れたものを金継ぎしながら命を次へ還流させる。
この衝突が本作の中心である。

### 2.1 時代考証の運用原則（神話世界の整合）

本作は「神話としての真実」を優先します。史実の年代と厳密一致は必須ではありません。
時代考証の揺らぎは、次の条件を満たす場合に限り許容します。

- 神話語彙に翻訳できる。
- 「常世」という時間超越領域、または祭具・神意で由来を説明できる。
- 神術・魔術・呪法・怪異譚など、超常の作法として整合している。
- 世界観の主軸（停滞と還流の衝突）を強める。

一方、未来文明を直接連想させる要素は採用しません。
特に、電子計算機器・近未来兵器・現代工業機械・ネットワーク依存描写は、ゲーム内文言へ入れません。

> **カグツチ의 神話的 位相의 再定義:** 本作において火之迦具土神（カグツチ）は、イザナミが産み落とした瞬間、産湯の熱で母を焼き殺した「最初の悲哀と恐怖の根源」である。この焼死によってイザナギが喪失の苦痛と「二度と失いたくない」という絶望的な執着に駆られ、世界を永遠の琥珀に凍らせることを決意させた張本人である。カグツチは天津神でも国津神でもなく、イザナギの悲劇（トラウマ）から直結する「原初の怨念」として存在する。タケミカヅチはこの「母を焼き殺した忌むべき兄」の血脈を引き、その怨念が灼熱たたら場の最奥に封じられている。マヒトとミコトの禁忌鍛造がこれを呼び覚ます第3幕の試練は、イザナギの永遠なる停滞への執念そのものとの立ち向かいとなる。

### 主人公ミコトの本性：結晶世界を支える「要石（かなめいし）」
主人公ミコトは、ニニギノミコトを原型とする、感情を持たないよう設計され神の命令だけを通すための入れ物、すなわち「空の器」である。
そのうえで本来は地上を平定したのち、結晶世界が二度と揺らがないよう中心で支え続ける「要石」になる設計だった。
ただし器に最初に与えられた役割は、すぐにその座へ据えられることではなく「神代の処刑者」である。天命のもと、地上の命を無感情に結晶化し続けた。

転機はカガセオ決戦。瀕死のカガセオから逆流した情念が器を内側から焼き、全記録を焼失させる。ミコトの記憶喪失はこの時点で発生した。機能不全となったミコトは葦舟（アシブネ）で黄泉と常世の狭間へ流棄される。だが狭間から現世へは本来出られない。そこで、天の理に反逆したスサノオがただ一度だけ暴風を差し込み、葦舟を現世の潮へ押し出した。これが「アシブネノミコト」の由来であり、ヒルコ神話への反復でもある。

記憶喪失のまま漁村アマへ漂着したミコトは、人間の熱とカガセオ破片に触れることで、天の計算を狂わせる存在へ変容する。

クリア後導線は「スサノオ試練」から真裏ボス「澱神・八岐の産土」へ続く。天叢雲剣は授与品ではなく、八岐の尾から露出した剣核を現行武器へ金継ぎ接合して覚醒させる。本作の勝利は「強武器の取得」ではなく、「痛みの履歴の受容と再接合」にある。

### 結末の哲学：永遠の拒絶（イワナガとサクヤの分解再構成）
本作は「コノハナサクヤヒメ（寿命と変化）」と「イワナガヒメ（不変と永遠）」の逸話を分解して再構成する。
主人公は終端で、神の特権である永遠の静止を拒否し、朽ちる寿命と劣化を選ぶ「最初のただの人間」として着地する。
完全閉鎖された系に「寿命（劣化と死）」という不可逆要素を導入することが、神話からの独立行為である。

## 3. ゲームデザイン原則 (深い洞察)

すべての遊びの体験、戦いの見せ方、舞台構成は次の原則で設計します。
**「このゲームの仕様は、効率消費ではなく、泥臭い修復と継承を体感させるためにある。」**

### 3.1 神の振る舞い（敵側の作法）
- **静謐とエントロピーの凍結:** 神々は自己の傷を極端に恐れ、世界を完全に予測・管理しようとする。
- **最適解の押し付け:** 戦闘時、神は「完璧に計算された兆候」を示し、プレイヤーを理の中へ閉じ込めようとする。行動に無駄はなく、徹底して理にかなっている。

### 3.2 人の振る舞い（味方・プレイヤー側の作法）
- **ノイズと摩擦による反逆:** プレイヤーは神の計算を上回るのではなく、神が理解できない「非合理な熱量（自傷、過熱、代受苦など）」を用いることで、神の読みそのものを乱す。
- **神を圧倒する狂気（死狂い）:** あえて死の淵（活魂ゼロ）へ飛び込む際、死狂い系パッシブを保持している者のみが情念を媒介に狂動へ遷移し、神の最適予測そのものを物理的に爆砕する。
- **傷の肯定（金継ぎ）:** 傷つくことを恐れないのではなく、傷ついた器を「星の砂（金継ぎの光）」で美しく修復し、その修復の歴史（Friction）自体を強さの源泉とする。
- **付喪神顕現と必殺連動:** 金継ぎ履歴が閾値を超え、付喪神として意志を持った相棒のみが極大代受苦を許可される。必殺は消耗の延長ではなく、相棒の存在証明と引き換えに世界の結晶化へ亀裂を入れる契約行為である。
- **情念の核（Core_of_Regret）:** 極大代受苦によって付喪神化武器が消滅したときのみ生成される、武具に宿った「後悔と執着の凝縮体」。別ベース武器への継承を可能にする特殊物質。
- **白堊の回廊の絶望:** 第2幕中盤、ヤマトへの唯一導線「白堊の回廊」では白化神守護兵の完璧な見切りが連続。ウズの狂騒による内側からの爆砕まで既存手段は通らず、この体験がマヒトの禁忌鍛造（Lv2）導線を成立させる。
- **段階的鍛造解放:** マヒト加入後に段階的に機能を解禁（野営Lv0〜拠点Lv3神器錬成まで）。
- **物理現象の神話的翻訳:** SF的なガジェット用語を避け、「熱量、残留応力の解放、摩擦、接地の放電、星の瞬き」などの物理現象として神話世界へ翻訳する。

### 3.3 外部参照要素の翻訳原則（DQ要素の昇華）
- **直輸入の禁止:** 外部RPGの記号（メタル系、封印、反射、テンションなど）を名称や数値だけで移植しない。必ず「結晶化 vs 還流」の対立軸へ翻訳してから導入する。
- **本作での採用翻訳:**
	- 「メタル系」→ **剥落の星屑**
	- 「特技封じ」→ **凍結の真空**
	- 「場ルール改変」→ **無菌の帳 / 血の泥沼**
	- 「テンション」→ **共鳴過熱**
	- 「反射」→ **理の反射鏡**
- **氷の二重定義（静止と冷却）:**
	- 神の氷 = **静止（Stagnation）**。
	- 人の氷 = **冷却（Cooling）**。暴走する熱を鎮めるための物理的な知恵。

## 4. ビジュアル・フィロソフィー（同一キャンバス原則）

この世界は、「一枚の生きた和紙（Washi）」の上に、「岩絵具（Iwa-enogu）」という同一の画材で描かれる。画材ではなく**「筆致（マチエール）」**のみで天（神）と地（人）を表現する。

- **天の理（神）:** 滲みを最小限に抑えた、端正で冷酷な細線と制御。
- **地の泥（人）:** 和紙の線を引っ掻くような掠れ（Kasure）と、岩絵具の奔放で不規則な滲み（ノイズ）。

## 5幕のあらすじ

1. **第1幕【胎】**: 漂着したミコトが、うかみとスクナと旅立つ。
2. **第2幕【融】**: 白堊の回廊で敗北し、禁忌鍛造（修復の重要性）を知る。
3. **第3幕【熾】**: 真実と対峙し、神の理への反逆を選ぶ。
4. **第4幕【結】**: 黄泉で再起動し、天岩戸をこじ開ける。
5. **終幕【還】**: 劣化と死を受け入れ、永遠の保存を拒絶する。

## 遊び方の骨格

| 管理リソース | 体験の感触 | 枯渇時のリスク |
|---|---|---|
| **活魂（体力）** | 前線に立てるか | ゼロで倒れる |
| **情念（気力）** | 技を回せるか | 枯れると「空殻」になり行動不能に陥る |
| **武器耐久度** | 攻勢を維持できるか | 壊れて使用不能、修復（金継ぎ）が必要 |
