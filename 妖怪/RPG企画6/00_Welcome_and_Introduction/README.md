# RPG企画6 — アシブネノミコト 〜天降る御子と、星屑の大地〜

壊れながらも生き続ける命と、悲しみをなくすために世界を止める神が衝突する、和風神話ダークファンタジーRPGです。

この文書は、初見プレイヤーと初参加メンバーのための案内所（Front Desk）であり、世界観とデザインの根幹を定義する「正本」です。

## 30秒で分かるこのゲーム

- **一言**: 壊れた武器を金継ぎで直しながら進む、泥臭い再生RPG
- **戦いの軸**: 活魂（体力）・情念（気力）・武器耐久度（壊れるまでの残量）
- **物語の軸**: 永遠の静止を望む神と、有限の命を選ぶ人の衝突
- **主人公**: 感情のない器だったミコトが、人として生きることを選び直す旅

## コア対立

- **天の理**: 悲しみを消すため、世界を永遠の結晶へ固定する
- **地の情念**: 傷と劣化を抱えたまま、命を次へ還流させる

本作は善悪の二元論ではなく、二つの救済思想の衝突として構成します。

## デザイン原則

1. **テーマ優先**: すべての仕様は「停滞 vs 還流」を体験として可視化する。
2. **破損の肯定**: 強化ではなく、破損履歴をつなぐ行為を成長の中心に置く。
3. **神話語彙の保持**: SF語彙を避け、和風神話の言葉で統一する。
4. **相転移の物語曲線**: 固相 → 液相 → プラズマ相 → 再結晶 → 相転移 の遷移を体験に同期させる。
5. **神話翻訳の徹底**: 外部RPG記号はそのまま使わず、本作語彙へ翻訳して採用する。

## 世界の舞台

| 場所 | 役割 | 特徴 |
|---|---|---|
| 高天原 | 神の領域 | 完璧だが冷たい、絶対零度の「無菌」世界 |
| 葦原中国 | 地上世界 | 人が傷つき、直し、次へ渡す「循環」の世界 |
| 黄泉の国 | 未練の地 | 停滞が堆積し、回復すら毒に転じる領域 |
| 常世の国 | 最終牢獄 | 神が目指す「永遠保存」が完成した場所 |
| 根の堅州国 | 反逆の果て | 神の理が届かない、命の根源的な到達点 |

## 主要人物（物語の見取り図）

- **ミコト**: 天の器として造られ、地上で人へ変わる主人公。仲間の技を写し取る。
- **うかみ**: 前線で仲間を守る壁役。赤いスカーフをミコトに託した最初の庇護者。
- **スクナ**: 劇薬と冷徹な判断で崩しを作る薬師。無菌の理に毒を突きつける。
- **ウズ**: 行動順と予測を乱す攪乱役。停滞したリズムを破壊する。
- **タチバナ**: 自傷を代償に敵全体を弱める呪術役。生存意志の強度を示す。
- **マヒト**: 壊れた武具を再起動させる鍛冶師。破損履歴を価値へ変える。
- **ワカヒコ**: 危険行動を止める狙撃手。神側の理を知る反逆者。

## 5幕のあらすじ

1. **第1幕【胎】**: 漂着したミコトが、うかみとスクナと旅立つ。
2. **第2幕【融】**: 白堊の回廊で敗北し、禁忌鍛造（修復の重要性）を知る。
3. **第3幕【熾】**: 真実と対峙し、神の理への反逆を選ぶ。
4. **第4幕【結】**: 黄泉で再起動し、天岩戸をこじ開ける。
5. **終幕【還】**: 劣化と死を受け入れ、永遠の保存を拒絶する。

## 遊び方の骨格

| 管理リソース | 体験の感触 | 枯渇時のリスク |
|---|---|---|
| **活魂（体力）** | 前線に立てるか | ゼロで倒れる |
| **情念（気力）** | 技を回せるか | 枯れると「空殻」になり行動不能に陥る |
| **武器耐久度** | 攻勢を維持できるか | 壊れて使用不能、修復（金継ぎ）が必要 |

## メタファー・位相語（開発・世界観補足）

制作時は次の「位相遷移」を基準にします。

- **固相**: 停滞の始まり（第1幕）
- **液相**: 交じり合う摩擦（第2幕）
- **プラズマ相**: 臨界を超える熱の爆発（第3幕）
- **再結晶**: 砕けた破片の再構成（第4幕）
- **相転移**: 永遠への拒絶と還流への回帰（終幕）

## 運用ルール

- **Zero-Loss原則**: 固有語彙、数値、条件式を削らない。
- **保護語彙**: 情念 / 活魂 / 武器耐久度 / 付喪神化 / 代受苦 / 極大代受苦 / 神の理 / 金継ぎ / 剥落の星屑 / 神託崩壊 / 無菌の帳 / 血の泥沼
