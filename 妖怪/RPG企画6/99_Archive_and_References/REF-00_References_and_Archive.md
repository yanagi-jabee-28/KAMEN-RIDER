# [REF-00] References and Archive

このファイルは「外部参照基準」および「プロジェクト履歴」の正本です。用語の翻訳、他作品の参照方法、およびこれまでの変更経緯を記録します。

## 1. 翻訳辞書 (Translation Map)

世界観を統一するため、外部語彙やSF語彙を以下の基準で翻訳して使用します。

### DQ・外部RPG由来
| 外部語彙 | 本作語彙 | 効果・設計の要点 |
|---|---|---|
| テンション | **共鳴過熱** | ゲージ化せず、情念と耐久度の相互作用として実装。 |
| メタル系 | **剥落の星屑** | 高防御・即帰還のレア雑魚。 |
| 封印 / 呪文封じ | **凍結の真空 / 理の断絶** | 行動の静止として再解釈。 |
| 反射 | **理の反射鏡** | 限定的な反射条件を設定。 |

### SF / メタ語彙（禁止語置換）
| 禁止語 | 推奨語 | 運用上の注意 |
|---|---|---|
| AI / システム | **神意 / 神託** | 機械的な意思ではなく神格の意思として扱う。 |
| ナノマシン | **祟りの粒 / 呪い** | 微細な物理干渉を呪術として説明。 |
| データ | **神話記録 / 履歴** | 実装値は SYS-30、本文は神話語彙。 |
| クラッシュ | **破綻 / 崩落 / 断絶** | ゲーム内テキストに現代語を残さない。 |

## 2. 外部参照ルール (External RPG Reference)

外部作品の仕様を参考にすることは構いませんが、以下の手順を必須とします。
1. 名称だけでなく、「効果・条件・コスト・対象」をセットで翻訳する。
2. 神話語彙へ置換できない要素は採用しない。
3. 採用の判断は、本ファイルの下部「変更履歴」に根拠を記録する。

## 3. 変更履歴 (Changelog)

### 2026-03-23
- **代受苦二相運用の正式化**: 代受苦を「防御型（致命肩代わり）」と「攻撃型（耐久燃焼で突破窓を作る）」へ公式分離。
- **極大代受苦の権利定義更新**: 極大代受苦は特定キャラ専用ではなく、全員に行使権がある方針へ統一。ただし武器履歴と同調条件を満たす場合に限定。
- **うかみ時代差分の固定**: 斥候うかみは葛城山での一瞬顕現、行者うかみは黄泉・常世での自律介入という意味差を `NAR-10` / `SYS-20` / `SYS-22` に同期。
- **終幕題名の確定反映**: 終幕サブタイトルは「永劫の放熱」で確定し、入口・物語・美術文書へ同期。
- **却下事項の明文化**: 「極大代受苦の特定キャラ専用化」および「代受苦を単一用途のまま維持する案」を不採用として確定。

### 2026-03-22
- **状態異常の最小統合（会議反映）**: 毒/混乱/服従の深度運用を既存定義へ注記として統合し、ID大量追加を回避。
- **武器劣化の正式化更新**: 武器劣化は「錆→蝕→朽」の3段階を正式採用。朽は極危険状態として即時対処が必要。
- **定義の厳密化**: 劣化段階は耐久度の高低と同義ではないことを正本へ明記。朽は破損（耐久0）と別概念であることを維持。
- **参照追加**: 仕様議論ログとして `REF-00_merged_gemini.md` を継続参照。
- **空殻復帰の限定化**: 空殻復帰は「情念回復/鼓舞/再起/劇薬」タグ技および代受苦余波に限定。単純な活魂回復技は対象外に固定。
- **黄泉戸喫の段階解放**: 第4幕導線で「遭遇→理解→解放」の順序を固定し、理解前のコマンド使用を禁止。
- **実体二刀流のナラティブ・ロック**: 序盤は同調補助占有により二刀流不可、葛城山の継承手甲恒久化後に解放へ統一。
- **時間単位の統一**: 公開文書を含む全レイヤで `Tick` 表記へ統一し、`ターン` 表記を廃止。
- **死狂い持続条件の更新**: 死狂いは `1Tick` 固定ではなく、情念が尽きるまで継続する仕様へ統一。
- **代受苦の語義固定**: 代受苦は通常防御の上位ではなく、武器へ致死因果を肩代わりさせる契約処理として明文化。
- **神写し枠の扱い更新**: 葛城山継承以後の固定継承は既存神写し枠の占有ではなく、固定継承枠の増設として統一。
- **劣化段階の定義強化**: 錆/蝕/朽は耐久値段階ではなく、`Durability_Drain_Rate`（耐久減少速度）段階として固定。

### 2026-03-21
- **鍛造Lv2解放条件の固定**: 拠点鍛造は `MAHITO_JOINED_ACT2`（マヒト加入直後）、野外Lv2はタケミカヅチ雪辱後（`TAKEMIKAZUCHI_REVENGE_CLEARED`）へ統一。
- **黄泉戸喫仕様の統一**: 「プレイヤー任意使用」と「行者うかみ自律摂取（在庫非消費）」の併用仕様を DEV-10 / DEV-11 / SYS-20 / WRD-02 で同期。
- **差分監査**: 仕様削除は行わず、条件明文化と追跡導線の補強のみを実施。

### 2026-03-20
- **REF-50詳細移植**: `RPG企画5/05_References/REF-50_Reference_DQ_Master_Data.md` の詳細データを `REF-50_External_RPG_Reference_Dictionary.md` へ統合。
- **参照整合**: 依存先を `SYS-20_Player_Manual` / `SYS-30_Data_and_Logic_Architecture` に統一し、RPG企画6の運用前提へ更新。

### 2026-03-19

- **構造の整理**: 00〜03番をプレイヤー・世界観向け、90〜99番を開発者・管理向けに分離。
- **SSOTの徹底**: SYS-30 を数理的な唯一の正本として固定。

## 4. プロジェクト履歴・廃棄案の全記録 (Full Archive)

> [!NOTE]
> 本節は `RPG企画5/WRD-99` より継承された全履歴です。不採用案の背景を確認し、設計の再発を防止するために保持されます。

### 4.1 QOL向上・ナラティブ昇華による仕様変更

- **2026-03-17: 終盤導線A確定・天叢雲剣覚醒条件統一**
  - 終盤順序を「本編カガセオ → クリア後スサノオ試練 → 真裏ボス澱神・八岐の産土」に確定。
  - 天叢雲剣は単純取得ではなく、剣核を現行武器へ金継ぎ接合して覚醒させる。
- **2026-03-17: ミコトのバックボーン根本再構築**
  - 前歴を「神代の処刑者」として確立。カガセオとの決戦による情念逆流で全記録（記憶）を焼失。
  - 第1幕に「天の軍勢の二次襲撃」を追加し、離村動機を能動的なものへ変更。
- **2026-03-16: 天球三相変化の設計確定**
  - 世界の空を「斜陽 → 永遠の極夜 → 絶対暗黒 → 昼夜の還流」の四段階で遷移させる。
  - ツクヨミを「過剰浄化の執行者」かつ「太陽消失後のフェイルセーフ守護者」と再定義。
- **2026-03-13: アーキテクチャ完全整合・冷却戦術追加**
  - `DualStanceActive` による仮想双腕化。
  - 「情念の核（Core_of_Regret）」への呼称統一。
  - 属性定義に `ICE_COOLING` を付与し、澱神への有効戦術化。

### 4.2 廃棄・昇華された主要案

- **「武具の墓標」 → 「星継ぎの系譜」**: ペナルティ表現から「共に戦った軌跡」へのポジティブな転換。
- **「うかみの遠隔守護」の撤廃**: 空間的な絶望と黄泉での再会のカタルシスを優先し、地上戦支援を廃止。
- **「赤いスカーフの焼失」の撤回**: ビジュアルシンボル維持のため、退色や焼失はさせず永続保持。
- **「通常戦闘でのロスト」制限**: プレッシャー緩和のため、完全ロストはボス戦限定へ。
- **「SF要素（AI・ナノマシン）」の神話翻訳**: あらゆる機械的ガジェットを「神託」「祟りの粒」等の和語と物理現象へ翻訳。
