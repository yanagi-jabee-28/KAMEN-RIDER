## 2. 特技 (Skills)

### 物理スキル
- **火炎斬り / しんくう斬り / マヒャド斬り**: 属性付加斬撃。
- **メタル斬り / 黄泉送り / ドラゴン斬り**: 系統特効攻撃。
- **はやぶさ斬り / つるぎのまい**: 多段・連続攻撃。
- **ギガスラッシュ / ギガブレイク**: 聖なる雷光による全体攻撃。
- **かぶとわり / やいばくだき**: ダメージ＋デバフ。
- **まじん斬り / 一閃突き**: 急所狙い（会心の一撃）。

### ブレス (Breath)
- **火炎の息 / しゃくねつ / 煉獄火炎**: 炎属性ブレス。
- **凍える吹雪 / かがやく息 / 絶対零度**: 氷属性ブレス。
- **甘い息 / どくの息 / いてつく波動**: 状態異常・バフ解除ブレス。

## 3. 装備品 (Equipment)

### 代表的な武具
- **伝説**: ロトのつるぎ、天空のつるぎ、勇者のつるぎ。
- **特殊**: どくばり（即死/1点）、はやぶさの剣（2回攻撃）、まじんのかなづち（会心）。
- **防具**: メタルキングの盾（高耐性）、みずのはごろも（属性軽減）、ひかりのドレス。

## 4. アイテム・素材
- **回復**: やくそう、せかいじゅの葉、せかいじゅのしずく、エルフの飲み薬。
- **成長**: ちからのたね、命のきのみ（恒久強化）。
- **素材**: オリハルコン、ヒヒイロカネ、メタルのカケラ。
