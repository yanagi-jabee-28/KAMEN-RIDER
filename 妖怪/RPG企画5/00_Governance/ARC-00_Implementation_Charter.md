# アシブネノミコト 〜天降る御子と、星屑の大地〜


# [ARC-00] 実装ルールブック

## 0. Zero-Loss翻訳規約（全ドキュメント共通）

この章は、仕様を落とさずに読みやすくするための共通ルールです。

- 固有語彙・システム語彙・数値・条件式・フラグ名は改変しない。
- 平易化は「置換」ではなく「補助説明の追記」で行う。
- 学術借用語は、必要に応じて和語の補助表現を併記する。
- 解釈が衝突したら `SYS-30` → `SYS-20` → `WRD-01` の順で確認する。

### 0.1 保護語彙（変更禁止）

以下は世界観と仕様を兼ねるため、要約・省略・別語への置換を禁止する。

- 情念
- 活魂
- 武器耐久度
- 付喪神化
- 代受苦
- 極大代受苦
- 神の理
- 金継ぎ
- 剥落の星屑
- 神託崩壊
- 無菌の帳
- 血の泥沼

### 0.2 メタファー翻訳の実務ルール

難解語を消すのではなく、「本文の意味を保ったまま補助線を引く」運用を標準化する。

- 固相 / 液相 / プラズマ相 / 再結晶 / 相転移
  - 停滞の始まり / 交じり合う摩擦 / 臨界を超える熱量の爆発 / 砕けた破片の再構成 / 永遠の拒絶と命の循環への回帰
- ルードナラティブ
  - 遊びの体験を通じた物語表現
- ホルミシス効果
  - 致死の劇薬による強制的な生命活性化
- ピアサポート
  - 自傷を伴う痛みの分かち合いと共鳴
- マチエール
  - 岩絵具が厚く塗り重ねられた物理的な凹凸
- シンコペーション
  - 完璧な拍子を崩す裏拍の乱れ
- SSOT
  - 唯一の正本となるマスターデータ

## 1. 世界観を守るルール

- ゲーム内テキストと正本仕様に、SF系の言葉を混入させない。
- 禁止語の例: AI, ナノマシン, データ, アルゴリズム, システムクラッシュ。
- 置換先の例: 神託, 呪い, 神の理, 祟り, 還流, 付喪神化。

### 1.1 語彙変換辞書（移行作業の審査基準）

| 禁止語彙 | 推奨語彙 | 備考 |
| --- | --- | --- |
| AI | 神託 / 神意 | 自律判断は「神意の執行」として記述 |
| ナノマシン | 呪い / 祟りの粒 | 微細干渉は呪術作用で表現 |

### 1.2 SF・メタ用語の資料内使用規則（読者・開発陣向けの例外）

ゲーム内文言の空気を守りながら、開発文書の実務性を確保するための規則です。

**許容される場面（ドキュメント内）:**
- 仕様書・データ定義では、UI、バグ、リサーチ、ティック、クラッシュ、サーチ、リブート等を使用可。
- 理由は、技術的正確性と、開発者同士の意思疎通速度を両立するため。
- 例: 「UIの崩壊を回避する」「バグ攪乱ゲージ」「行動Tickの遅延」。

**厳禁される場面（ゲーム内テキスト）:**
- プレイヤーが直接読む文言（セリフ、アイテム説明、システムメッセージ、実績テキスト等）では使用禁止。
- 必ず和語へ翻訳して実装する。
- 例: UI崩壊 → 神託崩壊、バグ攪乱 → 情念の奔流、リブート → 世界再起動。

**ゲーム内転用リスクのある叙述（準ゲーム内文言）:**
- 仕様書内の物語本文・演出文・スキル説明のうち、将来的にゲーム内テキストへ流用され得る箇所は、原則としてSF語彙を極力排除する。
- 例外として、スクナの語り口における医学・薬学由来の現代語（例：毒物学、薬理、ホルミシス等）は許容する。
- その他の例外語は、意図と範囲を同一段落内に明記した場合のみ許容する。

**管理方法:**
本セクションで定めた**禁止語彙と推奨語彙の対応表** を実装ガイドとして参照し、コード・テキストの自動検査を推奨する。

### 1.3 時代考証の許容境界（神話作品としての運用）

本作は厳密な史実再現ではなく、神話的世界の一貫性を優先する。時代考証における揺らぎは、以下の条件で許容する。

- **許容方針:** 神話語彙で意味づけ可能であり、世界観の対立軸（結晶化 vs 還流）を強化するなら、異時代的要素を限定的に採用してよい。
- **許容理由の核:** 「常世」は時間を超越した領域であり、そこで生じるズレは演出上の例外として扱える。
- **超常説明の許容:** 神術・魔術・呪法・民間信仰・怪異譚など、オカルト文脈で一貫して説明できる要素は採用できます。
- **非許容領域:** 未来文明を直接想起させる描写（近未来兵器、現代工業機械、電子計算機器、ネットワーク前提の概念）は、ゲーム内表現に採用しません。

判断に迷う要素は、以下の4条件をすべて満たす場合のみ採用候補とする。

1. 神話語彙へ無理なく翻訳できる。
2. 常世・祭具・神意のいずれかで由来説明できる。
3. 20世紀以降の固有技術知識を前提にしない。
4. 説明の主軸が科学技術ではなく、神術・魔術・オカルトの内的整合にある。


上記の解釈に揺れがある場合は、実装前に `WRD-99` へ判断理由を記録し、再発時の基準として共有する。
