## このゲームについて（初めて読む方へ）

日本神話をベースにした、暗めのファンタジー RPG です。
壊れた武器を直しながら旅を続け、最後に「神の永遠」に立ち向かいます。
このREADMEは、世界観と仕様の入口を最短でつかむための案内です。

| 項目 | 内容 |
|---|---|
| タイトル | アシブネノミコト 〜天降る御子と、星屑の大地〜 |
| ジャンル | 和風神話ダークファンタジー RPG |
| 遊び心地 | 武器を直したり、仲間に受け継いだりしながら進む、泥臭い旅 |
| 見た目 | 一枚の和紙に岩絵具で描いたような絵。神は細くきれいな線、人は荒々しい滲みで表現 |

### この世界の対立

神々は「大切な人を失う悲しみをなくしたい」という気持ちから、世界を止めようとしています。
人間たちは「傷ついてもいい、それでも生き続けたい」という気持ちで、それに抵抗します。
神が一方的な悪ではない点が、本作の重要な軸です。
どちらの側も「悲しみをなくしたい」という願いから動いています。

**舞台となる世界**

| 場所 | 説明 |
|---|---|
| **高天原** | 何も変わらない、完璧で冷たい神の場所 |
| **葦原中国** | 人や国津神が生き死にしながら暮らす、普通の世界 |
| **黄泉の国** | 神に捨てられた命が積もる場所。回復すら毒になる |
| **常世の国** | 神が目指す「完全に止まった美しい世界」。最後のダンジョン |
| **根の堅州国** | スサノオが流れ着いた、神の手が届かない場所 |

### 主人公と仲間

**ミコト（アシブネノミコト）:**
もともと天の命令で動いていた、感情のない「器」でした。星神カガセオとの戦いで記憶をすべて失い、葦舟に乗せられて海に流されます。漁村アマに流れ着いたとき、何も覚えていない状態からスタートします。地上の人たちと旅をする中で、少しずつ「ただの人間」になっていく話です。

**仲間（加入する順番）**

| 名前 | 加入 | どんな人か |
|---|---|---|
| **うかみ** | 第1幕 | 漁村アマの住人。ミコトに赤いスカーフを巻きつけた最初の人。第2幕で一度離れ、第4幕で再び戻ってくる |
| **スクナ** | 第1幕 | 薬師。皮肉っぽいが、劇薬で道を切り開く |
| **ウズ** | 第2幕前半 | 「狂騒」という技で、敵の完璧な守りを内側から破る |
| **タチバナ** | 第2幕中盤 | 忘却の海食洞で出会う少女。「誰かを生かすために死んでもいい」という執念を持つ |
| **マヒト** | 第2幕中盤 | 片目の鍛冶師。彼が加入すると、武器に魂を宿らせる「禁忌鍛造（Lv2）」が使えるようになる |
| **ワカヒコ** | 第3幕 | 天の監視役。ナキメとの戦いの後、一行に加わる |

**主な神々（主に敵側）**

| 名前 | 役割 |
|---|---|
| **イザナギ** | この物語の最終的な意志。世界を止めようとしている張本人 |
| **アマテラス** | 世界の管理者。悲しみをなくすために天岩戸に閉じこもり、世界の時間を止めた |
| **ツクヨミ** | 命を「永遠の眠り」に閉じ込めようとする。実はアマテラス封印後の世界を辛うじて保っている側面もある |
| **カガセオ（星神）** | 天に最初に逆らった者。砕けた破片が「星の砂（金継ぎの光）」の正体 |
| **ヒルコ** | 神話で最初に捨てられた命。第3幕でミコトの過去を暴く |

### バトルの仕組み

戦闘で使うリソースは3つだけです。新しいゲージは増えません。

| リソース | 意味 | 尽きたら |
|---|---|---|
| **活魂（Kakkon）** | 体力 | 戦闘不能。条件を満たすと「死狂い」に入る |
| **情念（Jonetsu）** | 技を使うための気力 | 「空殻」状態になり、技が使えなくなる |
| **武器耐久度** | 武器がどれだけ持つか | 武器が壊れる。金継ぎで直すまで使えない |

**死狂い（Shigurui）:**
活魂がゼロになっても、情念が残っていて、専用のパッシブを持っていれば、体が崩れながらも動き続けられます。この状態では神の攻撃を無視できますが、情念を使い切ると消えます。

**金継ぎと付喪神化:**
使い続けた武器は傷の歴史を蓄えます。金継ぎで直すたびに、武器に少しずつ意志が宿ります。十分な歴史を積んだ武器だけが「付喪神化（禁忌鍛造 Lv2）」し、最強の技「極大代受苦」が使えるようになります。強い武器を探すゲームではなく、使い続けた武器を繋ぎ直すゲームです。

**神と人の戦い方の違い:**

| 神（敵） | 人（プレイヤー） |
|---|---|
| 次の行動を完全に予告する。無駄がない | 神の計算を外れた、むちゃくちゃな熱量でぶつかる |
| プレイヤーの行動パターンを学習する | 死の淵に飛び込んで「死狂い」で予告を破壊する |
| 世界を止めようとする | 壊れながらも動き続ける |

| **第2幕【融】** | 滲む境界 | 白堊の回廊で完全に負ける。タチバナ・マヒトが加わり、禁忌鍛造が使えるようになる。うかみが離れる |

### 1. 語彙ルール — SF語彙は混入禁止

ゲーム内テキスト（セリフ・アイテム説明・システムメッセージ）では、現代語・SF語彙を使わない。
変換表の全体は [ARC-00 §1.1](00_Governance/ARC-00_Implementation_Charter.md) に定義されている。

代表例：

| 禁止語 | 使うべき語 |
|---|---|
| AI / システム | 神託 / 神意 |
| ナノマシン | 祟りの粒 / 呪い |
| データ | 神話記録 / 神の理 |
| クラッシュ | 破綻 / 崩落 |

なお、仕様書・開発ドキュメント内での実務的な技術語（UI、バグ、Tick等）は許容されている（[ARC-00 §1.2](00_Governance/ARC-00_Implementation_Charter.md) 参照）。
ただし、物語本文や演出文などゲーム内テキストへ転用され得る記述では、SF語彙を可能な限り避けること。スクナの医学・薬学語彙は例外として許容する。

### 2. コアテーマ — 全仕様の判断基準

本作の世界観は **「永遠の結晶化（停滞）vs 傷を抱えた命の還流（変転）」** の一文で要約される。

- **天の神々（イザナギの理）**：悲哀を恐れ、世界を不変の琥珀に凍らせようとする。
- **地上の者たち**：壊れたものを金継ぎしながら、命を次代へ還流させようとする。
- **主人公ミコト**：天の使者として降された「空の器」が、地上の熱に触れ「ただの人間」へ脱皮する。

この対立軸に反する記述は書かない。詳細は [WRD-01 §2](01_Worldbuilding/WRD-01_Core_Vision_and_Theme.md) を確認してください。

### 2.5 時代考証の扱い — 許容と禁止

本作は神話ファンタジーです。厳密な史実再現は目的にしていません。時代考証の揺らぎは、神話語彙と世界観整合が保てる範囲で許容します。

- 許容: 常世由来・祭具由来・神意由来として説明できる異時代要素。
- 許容: 神術・魔術・呪法・怪異譚など、オカルト文脈で世界観と整合する要素。
- 非許容: 未来文明を直接示す要素（電子計算機器、近未来兵器、現代工業機械、ネットワーク前提の描写）。

迷った場合は [ARC-00 §1.3](00_Governance/ARC-00_Implementation_Charter.md) の判定基準に従い、判断理由を `WRD-99` に記録してください。

## `ALL-files` の使い方

`ALL-files` フォルダは、主要ドキュメントの**配布用コピー置き場**です。
通常は追跡除外にし、リポジトリへコミットしない運用を推奨します。
（`.gitignore` に `ALL-files/` を追加）

コピー運用の利点は、共有先でリンク解決を気にせず直接開けることです。

**自動同期が必要な場合（任意）**

各ファイルを個別シンボリックリンクに差し替えると、元ファイル編集が即時反映されます。
以下は **ファイル単位** のリンク作成例です。

```powershell
# 例: 00_Governance 内の Markdown を個別リンクに置換する
cd '...\妖怪\RPG企画5'

# 既存コピーを削除（必要ならバックアップ後に実行）
Get-ChildItem -Path '..\ALL-files' -Filter *.md | Remove-Item

# 元ファイルをループしてリンク作成
Get-ChildItem .\00_Governance -Filter *.md | ForEach-Object {
    $target = $_.FullName
    $link   = Join-Path '..\ALL-files' $_.Name
    New-Item -ItemType SymbolicLink -Path $link -Value $target
}

# 他のサブフォルダでも同様
# 例: 01_Worldbuilding
# Get-ChildItem .\01_Worldbuilding -Filter *.md | ForEach-Object { ... }
```

PowerShell の `New-Item -ItemType SymbolicLink` はファイル単位でも利用できます。
ジャンクション (`-ItemType Junction`) はディレクトリ専用なので、個別ファイルには `SymbolicLink` を使います。

リンクを Git 管理下に置くことは可能です。ただし、リンク先がない環境では機能しません。

他のマシンへクローンした後にコピー運用へ戻す場合は、次を実行します。
```powershell
cd '...\妖怪\RPG企画5'
mkdir '..\ALL-files' -Force
python refresh_allfiles.py
```

コピーを手動で作成する最小手順:

```powershell
# 例: ARC-00 をコピーする
cd '...\妖怪\RPG企画5'
Copy-Item -Path '.\00_Governance\ARC-00_Implementation_Charter.md' -Destination '..\ALL-files'
```

新規ドキュメント追加時も同様に `Copy-Item` で反映します。
複数ファイルを扱う場合は、ワンライナーか専用スクリプトを推奨します。

現在は `妖怪/ALL-files` を通常フォルダとして使用しています。
ジャンクション運用に戻す場合は、`妖怪/ALL-files` を削除し、`New-Item -Path .\ALL-files -ItemType Junction -Value .\RPG企画5` を実行してください。

コピー運用では、編集元を `RPG企画5` 側に固定し、`ALL-files` は配布・参照用途に限定します。
